# Guia de Sobrevivência: IA para usuários de R

Livro aberto sobre como usar assistentes, agentes, MCPs e skills para programar em R. A primeira parte explica as ferramentas; a segunda mostra o que eu uso hoje e quais modelos e fluxos recomendo.

Leia em [academy.ekio.io/livros/ia-para-r](https://academy.ekio.io/livros/ia-para-r/).

## Como renderizar

O livro é um projeto [Quarto](https://quarto.org) e não executa código R.

```bash
quarto preview
```
